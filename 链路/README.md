# 链路目录说明

这个目录把 [../pipeline_board.html](../pipeline_board.html) 中的每条链路拆成单独的文件夹，每个文件夹里放该链路的思考、实施路线和推荐文献，避免混在一起。

| 文件夹 | 内容 |
|---|---|
| [00_总览_工厂级世界动作模型](00_总览_工厂级世界动作模型/README.md) | 问题定义：从 VLA＋WBC 到整厂；概念命名与文献检索结论；有限算力下的总体思路；各链路在分层结构中的位置 |
| [L1_STEP资产化与物理仿真](L1_STEP资产化与物理仿真/README.md) | STEP 资产化＋物理仿真作为世界模型 |
| [L2_扫描配准与数字孪生](L2_扫描配准与数字孪生/README.md) | 扫描配准到 STEP 资产，并校准成数字孪生 |
| [L3_扫描单体化生成资产](L3_扫描单体化生成资产/README.md) | 没有 STEP 的设备：扫描单体化后生成资产 |
| [L4_PLC联仿与产线离散事件](L4_PLC联仿与产线离散事件/README.md) | PLC／NC 接入仿真，再接产线离散事件 |
| [L6_仿真加学习混合](L6_仿真加学习混合/README.md) | 仿真＋学习：残差、外观与快速代理 |

| [L9_潜变量模型式强化学习](L9_潜变量模型式强化学习/README.md) | 潜变量模型式强化学习 |
| [L10_视频世界模型](L10_视频世界模型/README.md) | 视频世界模型：合成数据与策略评估 |

| [专题_形变流体断裂与加工](专题_形变流体断裂与加工/README.md) | 不是链路，是跨链路的任务条件：任务涉及形变、流体、断裂或材料去除时，各链路要补什么；仿真器能力对照；加工（原 L5） |

阅读顺序：先读 00 总览，再读 L11，最后按需要看 L1–L10；任务涉及形变、流体、断裂或加工时，再读专题。

L5 编号空缺：原 L5「加工与形变过程模型」已改为上面的专题，因为形变等是任务条件，不是一条独立链路。其余编号保持不变，以免打乱已有引用。

## 约定

- 文献编号 P01–P99 对应 [../papers/](../papers/) 中的本地 PDF；带 arXiv 号的文献是本轮新核对的，暂未下载到本地。
- 文中"文献证据"是论文报告的内容；"思考"和"idea"是本目录作者的推导或设想，尚未验证。
- 本目录列出可行路线和实施方法，不对路线做优先级排序。
- 算力假设：几张 RTX 3090／4090（24 GB），加极少量 40 GB／80 GB 级别的卡（A100、A6000 等）。

写于 2026-11-20；2026-11-22 把 L5 改为专题，并在 L8 补充 INTACT 与 SADL 的仿真可行性分析。
