# works：工厂级世界模型的研究步骤

目前没有公开的工厂级世界模型，也没有对应的数据集。这个目录把研究拆成 17 项工作、6 个阶段：先定义问题和评测，再解决数据，然后做子级（机器人与工位）和整厂层的模型与决策，最后做安全校核、评测和部署。有些工作之间要反复迭代，用 6 个闭环表示。

打开 [research_board.html](research_board.html) 看总图：蓝色实线是顺序交付，红色虚线是闭环；点击卡片可看上下游和精选文献。每项工作有一个文件夹，写明要解决的问题、具体任务、可以写成论文的方向和高价值参考文献。

整厂层的目标按 WWC（Whole World Control，全场统一控制）表述：比 WBC 高一级，场景内的机器人和设备由同一个模型统一控制，而不是每台机器人一个控制器、上层再由 Agent 协调；工厂中的 WWC 即 FWAM，定义见 [../链路/00_总览_工厂级世界动作模型](../链路/00_总览_工厂级世界动作模型/README.md) 第 1.3 节。

本目录不推荐技术路线。各条链路（STEP 资产化、扫描孪生、JEPA、视频模型等）的做法见 [../链路/](../链路/README.md)；本目录回答的是“按什么顺序做研究、每一步做什么、哪里能出论文”。

统计：17 项工作，42 个论文方向，引用 262 篇不重复的文献和文档，104 个开源项目。

## 六个闭环

- ① **主动与反事实数据**：W09·W10 找出误差大或不确定的状态 → W11 选状态，设计动作扰动 → W03·W04·W05 从快照复位，执行并记录 → 回训模型。W09 或 W10 有了第一个可用模型时启动；误差和不确定性不再下降，或仿真预算用完时停止。
- ② **仿真—真实校准**：W07 真实工位采集轨迹与日志 → W08 比对仿真，辨识参数，学残差 → W02·W03·W04 更新资产参数、场景与节拍 → W05·W12 重新生成数据，重训技能 → 上真机执行。有第一批真实数据时启动；关键指标的仿真—真实差距低于设定阈值时暂停，现场变化时重启。
- ③ **场景—任务联合生成**：W03 生成或编辑场景 → W05 生成任务与示范 → W03·W05 统计失败、不可达与遮挡原因 → 按原因编辑场景。W02 有了第一批资产时启动；任务生成成功率和多样性达到要求时停止。
- ④ **世界模型—策略协同**：W09·W10 预测动作后果 → W12·W14 在模型中规划或训练 → 仿真或真实执行 记录新轨迹 → 更新模型。模型和策略都有初版时启动；策略在模型之外的收益不再提高，或模型预测与执行结果的偏差开始变大时停止。
- ⑤ **跨层一致**：W12 执行技能，返回事件与实际耗时 → W09 工位层预测同一事件 → W10 整厂层预测同一事件 → W14 按预测下发新命令 → 下发命令。两层都有模型时启动；层间预测一致率稳定后转为监控。
- ⑥ **评测—部署飞轮**：W16 评测，找出失败模式 → W17 部署，记录失败与人工干预 → W07·W04 采集真实片段与事件日志 → W11·W05 生成反事实与针对性数据 → 回训后再评测。第一个真实工位接入后按周期运行；每一轮更新都要通过 W16 的回归测试。

| 阶段 | 产物 | 进入下一阶段的证据 |

| S1 数据基础 | 可仿真设备资产；带设备逻辑、可从快照复位的车间场景；事件日志；机器人示范与全身动作库；真实同步数据；校准参数 | 缩小版工厂能复位并注入派工动作；每类任务有足量示范；关键指标的仿真—真实差距有量化结果。 |
| S2 子级：机器人与工位 | 工位层世界模型（任一链路实现）；技能库与端口；经过标定的自报告 | 每个子级都能被端口调用；自报告的耗时与成功率有校准曲线。 |

| S4 安全校核与评测 | 约束规范与屏蔽层；分层基准与长时不复位的评测协议 | 候选动作都经过约束检查；基准覆盖分层指标和长时运行。 |
| S5 部署与数据飞轮 | 混合运行记录；失败与干预数据；回训流程与回归测试 | 混合运行（部分工位在仿真）有预测误差和决策收益的实测记录。 |

## 约定

- 形变、流体、断裂和加工是任务条件，不是单独的工作或阶段；任务涉及它们时，按 [../链路/专题_形变流体断裂与加工](../链路/专题_形变流体断裂与加工/README.md) 补相应能力（主要影响 W02、W03、W05、W09、W16）。
- 算力假设：几张 RTX 3090／4090，加极少量 40 GB／80 GB 级别的卡。各文件夹的“算力”一节只写论文或官方文档报告的数字。
- 新增的 arXiv 文献没有下载到 `papers/`，也没有导入 Zotero。
- 重新生成：`python3 scripts/verify_works_sources.py && python3 scripts/build_works.py`。

说明：arXiv 文献的标题取自 arXiv 页面元数据（2026-11-22 核对，2026-11-27 补充）；P 编号对应 `papers/` 中的本地 PDF；GitHub 仓库已用 `gh api` 核对，均未归档。“分析判断”表示本目录的推断，尚未验证。本文件由 `scripts/build_works.py` 生成，请改 `scripts/works_src/` 后重新生成。
