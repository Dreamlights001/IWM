                                                                                                         Abstract
                                               Robotic cutting of soft materials is critical for applications such as food processing, household automation, and
                                               surgical manipulation. As in other areas of robotics, simulators can facilitate controller verification, policy learn-
                                               ing, and dataset generation. Moreover, differentiable simulators can enable gradient-based optimization, which
                                               is invaluable for calibrating simulation parameters and optimizing controllers. In this work, we present DiSECt:
                                               the first differentiable simulator for cutting soft materials. The simulator augments the finite element method
                                               (FEM) with a continuous contact model based on signed distance fields (SDF), as well as a continuous damage
                                               model that inserts springs on opposite sides of the cutting plane and allows them to weaken until zero stiffness,
                                               enabling crack formation. Through various experiments, we evaluate the performance of the simulator. We first
                                               show that the simulator can be calibrated to match resultant forces and deformation fields from a state-of-the-art
                                               commercial solver and real-world cutting datasets, with generality across cutting velocities and object instances.
                                               We then show that Bayesian inference can be performed efficiently by leveraging the differentiability of the sim-
                                               ulator, estimating posteriors over hundreds of parameters in a fraction of the time of derivative-free methods.
                                               Next, we illustrate that control parameters in the simulation can be optimized to minimize cutting forces via lat-
                                               eral slicing motions. Finally, we conduct experiments on a real robot arm equipped with a slicing knife to infer
                                               simulation parameters from force measurements. By optimizing the slicing motion of the knife, we show on fruit
                                               cutting scenarios that the average knife force can be reduced by more than 40% compared to a vertical cutting
                                               motion. We publish code and additional materials on our project website at https://diff-cutting-sim.github.io.

                                               Keywords: robotic cutting, differentiable simulation, sim2real transfer

     D.1    Parameter Inference
     The following code snippet demonstrates how the differentiability of DiSECt can be leveraged to infer the simula-
     tion parameters from real-world force measurements. We instantiate our simulator to cut an apple in the same way
     it was cut in the real world, by applying a prescribed knife motion that follows the recorded end-effector trajectory.
     Note that the simulation settings which are loaded from a JSON file include the file name of the tetrahedral mesh
     of the fruit we cut, as well as settings pertaining to the cutting springs and contact model, the material properties,
     boundary conditions, and integration procedure, among others (see Table A2). Given the recorded force profile,
     we select the Adam optimizer to tune the simulation parameters in a way that the L2 error between the simulated
     and real force profile is minimized.
 1   from cutting import CuttingSim, load_settings, PredefinedCartesianMotion
 2   # load the simulation settings for a real apple
 3   settings = load_settings("experiments/config/real_apple.json")
 4   # create DiSECt instance with GPU support (CUDA) and enabled gradient computation
 5   sim = CuttingSim(settings, dataset="real", adapter="cuda", requires_grad=True)
 6   # load data (force, position measurements) that we recorded from the real robot
 7   with open("assets/real/apple/vertical_cutting_apple.pkl", "rb") as f:
 8       real_data = pickle.load(f)
 9   real_force = np.linalg.norm(real_data["force"][:, :3], axis=1) # force profile
10   real_dt = real_data["time"][1] - real_data["time"][0] # time step of the recorded measurements
11   ee_pos = real_data["position"][:, :3] # trajectory of end-effector 3D positions
12   ee_vel = real_data["velocity"][:, :3] # trajectory of end-effector 3D velocities
13   times = real_data["time"] # time stamps of the recorded real measurements
14   # create a prescribed knife motion from the recorded end-effector trajectory
15   sim.motion = PredefinedCartesianMotion(q=ee_pos, qd=ee_vel, time=times)
16   # select reference force profile, optionally interpolate in case the recording time step does
17   # not match the simulation time step
18   sim.load_groundtruth(real_force, groundtruth_dt=real_dt)
19   sim.cut() # preprocessing step that cuts the mesh and inserts cutting springs
20   opt_params = sim.init_parameters() # retrieve tensors of simulation parameters to be optimized
21   opt = torch.optim.Adam(opt_params, lr=learning_rate)
22   # optimization loop in which the Adam optimizer tunes the simulation parameters to minimize the L2 error
23   # between the real and simulated force profile
24   for iteration in range(num_iters):
25       hist_knife_force = sim.simulate() # simulate a force profile
26       # compute L2 loss of force profile against ground-truth
27       loss = torch.square(hist_knife_force - sim.groundtruth_torch[:len(hist_knife_force)]).mean()
28       # log some information of the inference process (loss, plot of force profile and knife trajectory)
29       logger.add_scalar("loss", loss.item(), iteration)
30       fig = sim.plot_simulation_results()
31       logger.add_figure("simulation", fig, iteration)
32       opt.zero_grad()
33       loss.backward()
34       # update the simulation parameters
35       opt.step()

     D.2    Slicing Motion Optimization
     In the following code snippet, we implement our trajectory optimization loop from subsection 5.5 where a lateral
     slicing motion is tuned to minimize the force that acts on the knife. Following Equation 10, we add hard constraints
     on the motion of the knife to ensure that the blade touches the cutting board at the end of the cut (i.e., the object is
     fully cut), and that the lateral motion does not exceed the length of the blade.
1    import mdmm # package that implements the Modified Differential Method of Multipliers (MDMM)
2    from cutting import CuttingSim, load_settings, SlicingMotion
3    # load the simulation settings for the right half of a real apple we cut before
4    settings = load_settings("experiments/config/real_apple_right.json")
5    # create DiSECt instance with GPU support (CUDA) and enabled gradient computation
6    sim = CuttingSim(settings, dataset="real", adapter="cuda", requires_grad=True)
7    slicing_waypoints = 5 # number of waypoints in the trajectory
8    slicing_kernel_width = 0.4 # widths of the kernels of the trajectory waypoints
9    # the following tensors parameterize the knife motion, and require gradients to be optimizable
10   slicing_amplitudes = torch.tensor(np.ones(slicing_waypoints) * 0.001, requires_grad=True)
11   pressing_velocities = torch.tensor(np.ones(slicing_waypoints) * velocity_y, requires_grad=True)
12   slicing_frequency = torch.tensor(5., requires_grad=True)
13   # set up slicing motion of the knife with the parameters that we will optimize
14   sim.motion = SlicingMotion(
15       initial_pos=torch.tensor([0.0, sim.settings.initial_y, 0.], device="cuda"),
16       slicing_frequency=slicing_frequency, slicing_amplitudes=slicing_amplitudes,
17       pressing_velocities=pressing_velocities, slicing_kernel_width=slicing_kernel_width,
18       slicing_times=np.linspace(0.0, settings.sim_duration, slicing_waypoints))
19   sim.cut() # preprocessing step that cuts the mesh and inserts cutting springs
20   # add constraint to have the blade touch the ground at the end of the cut
21   knife_height_constraint = mdmm.EqConstraint(
22       lambda: sim.hist_knife_pos[-1, 1] + sim.blade_bottom_center_point_offset[1],
23       0.0, scale=height_constraint_scale, damping=height_constraint_damping)
24   # determine blade length and maximal lateral extents of the mesh
25   blade_length = sim.knife.depth
26   mesh_min_z = np.array(sim.builder.particle_q)[:, 2].min()
27   mesh_max_z = np.array(sim.builder.particle_q)[:, 2].max()
28   blade_min = mesh_max_z - blade_length / 2
29   blade_max = mesh_min_z + blade_length / 2
30   # add constraint to prevent the knife from moving laterally further than its blade length
31   blade_length_constraint = mdmm.EqConstraint(
32       lambda: (sim.hist_knife_pos[:, 2].clamp(blade_min, blade_max) - sim.hist_knife_pos[:, 2]).sum(),
33       0.0, scale=blade_constraint_scale, damping=blade_constraint_damping)
34   # set up MDMM optimization problem with the constraints; use Adamax as optimizer
35   constraints = [knife_height_constraint, blade_length_constraint]
36   mdmm_module = mdmm.MDMM(constraints)
37   parameters = [slicing_frequency, slicing_amplitudes, pressing_velocities]
38   opt = mdmm_module.make_optimizer(parameters, optimizer=torch.optim.Adamax)
39   # optimize knife motion parameters to minimize mean knife force while adhering to the constraints
40   for iteration in range(num_iters):
41       # objective is to minimize mean knife force
42       hist_knife_force = sim.simulate()
43       mean_knife_force = torch.mean(hist_knife_force)
44       mdmm_return = mdmm_module(mean_knife_force)
45       # log the current average knife force, add plots of the simulation and the trajectory parameters
46       logger.add_scalar("mean_knife_force", mean_knife_force.item(), iteration)
47       fig = sim.plot_simulation_results()
48       logger.add_figure("simulation", fig, iteration)
49       fig = sim.motion.plot(sim_duration=settings.sim_duration)
50       logger.add_figure("motion", fig, iteration)
51       opt.zero_grad()
52       # calculate gradient of the MDMM Lagrangian
53       mdmm_return.value.backward()
54       opt.step() # update motion parameters
